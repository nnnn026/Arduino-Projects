## HandPose_PWM_LED

p5.js의 ml5.js HandPose 모델을 활용해 웹캠으로 손동작(엄지-검지 거리)을 인식하고, Web Serial API를 통해 아두이노에 제어 신호를 보내 LED의 밝기(PWM)를 실시간으로 조절하는 프로젝트입니다.

---

## 1. 회로 구성 (Hardware Setup)

### 주요 부품

* Arduino Uno
* LED (1개)
* 220Ω 저항 (1개)
* 브레드보드 및 점퍼선

### 핀 연결 정보

* **LED Anode (+)** ➔ **220Ω 저항** ➔ **Digital Pin 11** (PWM 지원 핀)
* **LED Cathode (-)** ➔  **GND**

### Digital Pin 11 번을 사용한 이유

아두이노 우노에서 LED의 밝기를 단순히 켜고 끄는 것(HIGH/LOW)이 아니라, 미세하게 조절하기 위해서는 **PWM(Pulse Width Modulation, 펄스 폭 변조)** 기능이 필수적입니다.

아두이노 우노의 Digital 핀 중 물결표시(`~`)가 붙어 있는 핀(3, 5, 6, 9, 10, 11번)만이 PWM 출력을 지원하며, 본 프로젝트에서는 안정적인 PWM 신호 출력이 가능한 **11번 핀**을 제어 핀으로 선정하여 LED 밝기를 0부터 255 단계로 정밀하게 제어했습니다.

## 2. 스케치 및 주요 로직 설명 (Sketch Details)

### Web Serial API 연결 방식

별도의 로컬 서버(Node.js 등)나 시리얼 스플리터를 거치지 않고, 브라우저 표준 기능인 **Web Serial API**를 도입했습니다.

* `connectSerial()` 함수를 작성하여 사용자가 웹 화면의 **`아두이노 연결`** 버튼을 누르면 브라우저에서 직접 아두이노의 COM 포트를 선택 및 오픈(`baudRate: 9600`)하도록 구현했습니다.
* p5.js에서 처리된 제어 값을 `TextEncoderStream`을 거쳐 `PWM:수치\n` 형태의 문자열 패킷으로 아두이노에 직렬 전송합니다.

### 아두이노 핀 연결 및 파싱 방식

* 아두이노는 `Serial.read()`를 통해 문자를 읽어 들이다가 줄바꿈 문자를 만나면 수신된 명령어 버퍼를 확인합니다.
* `strncmp(command, "PWM:", 4)` 조건문을 통해 데이터 패킷을 판별하고, 뒤따르는 수치를 `atoi()`로 정수 변환하여 **Digital Pin 11**에 `analogWrite(LED2_PIN, pwmVal)`를 실행함으로써 LED 밝기를 변경합니다.

### 추가 세부 조건 설계 및 이유

1. **상태 변화 시에만 시리얼 전송 (`lastPwmVal` 비교)**
* **설계 이유**: p5.js의 `draw()` 함수는 초당 약 60프레임(fps)으로 실행됩니다. 매 프레임마다 시리얼 데이터를 보내면 아두이노 수신 버퍼에 과부하가 생겨 통신 지연(Delay)이 발생합니다.
* **해결**: 이전 프레임의 PWM 값(`lastPwmVal`)과 현재 계산된 PWM 값이 다를 때만 아두이노로 전송하여 데이터 전송 대역폭을 최적화했습니다.


2. **동적 정규화 및 감도 조절 (`maxRatio`, `minRatio` 설정)**
* **설계 이유**: 사용자마다 손 크기나 손가락 유연성이 달라, 엄지-검지 거리를 절대적인 픽셀 거리로 측정하면 최대로 펴도 슬라이더가 끝까지 도달하지 않는 문제가 발생합니다.
* **해결**: `v` (엄지-검지 거리)를 `p` (손목-중지 시작점 손바닥 길이)로 나누어 손 크기에 종속되지 않는 상대적 비율(`ratio = v / p`)을 구했습니다. 또한, 손을 다 펴지 않더라도 100% 밝기에 쉽게 도달할 수 있도록 상한선 기준 비율(`maxRatio`)을 정밀 조정하여 제어 편의성을 높였습니다.


3. **손가락 구부림 기반 제어 모드 (`isGrabMode`)**
* **설계 이유**: 카메라에 손이 찍히는 동안 계속해서 LED 밝기가 변경되면 의도치 않은 오작동이 발생할 수 있습니다.
* **해결**: 중지 손가락 끝(Keypoint 12)이 손바닥 안쪽으로 들어오는 '그랩 동작'을 취할 때만 제어 모드(`adjustMode`)가 활성화되도록 스위칭 조건을 구현했습니다.


4. **부드러운 값 보정 (Smoothening / Lerp)**
* **설계 이유**: 손가락의 미세한 떨림이나 카메라 인식 오차로 인해 LED 밝기가 덜덜 떨리는 현상을 방지합니다.
* **해결**: `slider.value(c + 0.05 * (v - c))`와 같이 이전 값에 보정 비율을 더해주는 보간 식을 적용하여 슬라이더와 LED 밝기가 부드럽게 변화하도록 처리했습니다.
