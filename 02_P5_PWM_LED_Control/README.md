# 🎬 Web Serial 기반 아두이노 PWM LED 밝기 제어 실습

p5.js의 세로 슬라이더 UI를 이용하여 웹 브라우저(Web Serial API)에서 아두이노 9번 핀 LED의 밝기(PWM)를 실시간으로 제어하는 프로젝트입니다.

---

## 📌 주요 특징 (Key Features)
* **웹-아두이노 연동**: Web Serial API를 활용한 양방향 시리얼 통신
* **비동기 태스크 처리**: `TaskScheduler` 라이브러리를 활용하여 통신 버퍼 오버플로우 방지 및 안정적 동작
* **통신 최적화**: `Math.abs()` 함수를 활용하여 슬라이더 값이 이전 전송값 대비 **5 이상 변화할 때만 데이터 전송** (불필요한 시리얼 트래픽 차단)
* **직관적인 UI**: p5.js 세로 슬라이더 및 실시간 0~255 수치 시각화

---

## 🔌 회로 구성 (Circuit Diagram)

* **Arduino Uno D9 (PWM 핀)** ➔ `LED (+ 다리 / 긴 다리)`
* **LED (- 다리 / 짧은 다리)** ➔ `220Ω (또는 330Ω) 저항` ➔ **Arduino GND**

> 💡 **참고**: LED 직렬 저항(220Ω)을 연결하여 과전류로 인한 LED 파손을 방지합니다.
